# Security Policy

Do not report vulnerabilities in public issues.

Repository administrators should create a
[draft security advisory](https://github.com/fabricOrg/fabric/security/advisories/new) and invite
the required collaborators. Other repository members should contact an administrator privately
before sharing the affected component, impact, reproduction, and any known mitigation.

Private vulnerability reporting for external reporters is unavailable on the repository's current
private organization plan. Do not include real credentials, customer data, phone numbers, message
bodies, or payment information in issues or discussions.

The project is pre-release. Security fixes target the latest `main`; no older versions currently
receive patches.
