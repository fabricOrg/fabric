# Security Policy

Do not report vulnerabilities in public issues.

Use the repository's
[private vulnerability reporting](https://github.com/fabricOrg/fabric/security/advisories/new) to
share the affected component, impact, reproduction, and any known mitigation. Do not include real
credentials, customer data, phone numbers, message bodies, or payment information.

The project is pre-release. Security fixes target the latest `main`; no older versions currently
receive patches.
