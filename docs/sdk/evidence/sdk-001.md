# SDK-001 contract normalization evidence

> Status: local release candidate verified - external publication not performed - 2026-07-15

## Outcome

The `@fabric-messaging/sdk` `0.1.0-beta.5` release candidate now uses one public environment and
webhook vocabulary, separates read and write options, validates known webhook payloads, handles
signed future events explicitly, and shares the closed API-key scope type with every API controller.

Public package publication and repository push are intentionally excluded because the user directed
that changes may be committed but must not be pushed. This evidence therefore proves an integrated
local release candidate, not an externally published release.
