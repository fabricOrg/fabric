# F3.7 — Low-balance alert

**Epic:** E3 Wallet · **Priority:** MUST · **Iteration:** 2–4
**Depends on:** F3.1, F1.2 · **Blocks:** —

## Why
Prevent silent service interruption: warn tenants before their wallet hits zero (Twilio's $5/$0
notification tier). Full auto-recharge + spend caps are PI-2.

## Stories
- **US-3.7.1** — As a **tenant**, I'm notified when my balance falls below a threshold, so I can top up before sends start failing.

## Acceptance criteria
- [ ] A per-tenant **low-balance threshold** (default + configurable).
- [ ] Crossing the threshold emits a `wallet.low_balance` event (F1.2) → notification (email/webhook).
- [ ] At zero balance, sends are rejected with a clear `insufficient_funds` error (already enforced by F3.2).
- [ ] De-duplicated: one alert per threshold-crossing, not per send.
- [ ] Test: a debit crossing the threshold fires exactly one alert.

## Design notes
- Auto-recharge floor + threshold spend-cap webhooks (Twilio UsageTrigger style) = **PI-2**.

## Out of scope (this PI)
- Auto-recharge; spend caps; usage-trigger webhooks.

## Definition of Done
- Threshold-crossing alert test (single fire); zero-balance rejection verified.
