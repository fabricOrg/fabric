# Website fonts

The website self-hosts Latin WOFF2 subsets so rendering does not depend on third-party requests.

- Clash Display 500, 600, and 700: Fontshare, under the Fontshare free font license.
- Inter 400-700: Google Fonts distribution, SIL Open Font License 1.1.
- JetBrains Mono 400-500: Google Fonts distribution, SIL Open Font License 1.1.

The files were retrieved from the providers' published CSS endpoints on 2026-07-26. Keep font
updates explicit so a provider change cannot silently alter the deployed brand typography.
