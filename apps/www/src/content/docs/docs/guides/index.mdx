## Production checklist

- Keep `sk_test_` and `sk_live_` keys in separate secret-manager entries.
- Set a unique idempotency key for every logical write.
- Verify webhook signatures against the raw request body.
- Persist event ids and make consumers idempotent.
- Treat money values as minor-unit strings, never floating-point numbers.
- Log Fabric request ids and your own business reference, but never message secrets or API keys.
- Handle rate limits and transient failures with bounded retries and jitter.
- Test terminal failures, duplicate events, and timeouts before going live.
