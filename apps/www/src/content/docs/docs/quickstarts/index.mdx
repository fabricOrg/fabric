## Before you begin

You need Node.js 22 or later, a Fabric application, a `sk_test_` secret key, and one published
message definition. The examples use the definition key `welcome.otp` with `name` and `code`
variables.

For direct HTTP integrations, use the [API reference](/docs/api-reference/). The SDK remains the
recommended path because it validates inputs, selects the environment from the key, parses response
shapes, retries eligible failures, and exposes typed errors.
