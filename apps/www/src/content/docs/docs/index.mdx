  </Card>

## Start in sandbox

<Steps>
1. **Create an application.** It owns the keys, environments, messages, webhooks, and activity for
   one integration.
2. **Create a test key.** Store the `sk_test_` key in your server-side secret manager as
   `FABRIC_API_KEY`.
3. **Send from your server.** Use direct content or address a published managed message by key.
4. **Follow the outcome.** Read the delivery or process its signed webhook event.
</Steps>

:::caution[Server-side only]
Fabric secret keys must never be exposed in browser code, mobile apps, public repositories, logs,
or client-visible environment variables. Call Fabric from a trusted server.
:::
